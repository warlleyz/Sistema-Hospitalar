# Sistema Hospitalar

Trabalho prático da disciplina de Programação Modular do curso de Engenharia de Software da PUC Minas.

## Objetivo

Desenvolver um sistema para gerenciamento das operações de um hospital, aplicando modelagem orientada a objetos e, nas próximas etapas, arquitetura em camadas, API REST com Spring Boot, persistência de dados, tratamento de exceções e testes automatizados.

## Sprint 1

A primeira sprint contempla:

- Front-end com telas sem funcionalidade;
- Diagrama de classes;
- Cartões CRC.

## Escopo inicial

O sistema deverá contemplar o gerenciamento de:

- Pacientes;
- Profissionais da saúde;
- Consultas;
- Internações;
- Quartos hospitalares;
- Histórico de atendimentos.
